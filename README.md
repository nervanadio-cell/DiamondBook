# DiamondBook

## Обновлено

- Фон страниц — фактура дубовой коры; книжные полки — дубовые доски, у каждой книги свой узор обложки.
- Обложку можно выбрать и кадрировать: область перемещается и растягивается за углы, выбранные пропорции не сбрасывают центр выделения.
- Название книги и главы редактируется на месте с кнопкой ✓; межстрочный интервал сохраняется для конкретной книги.
- В содержании по правому клику доступны переименование, добавление раздела, мультивыбор и удаление с оформленным подтверждением.
- Читалка показывает разворот двух страниц на широком экране; стрелки и `A/D` листают страницы, `W/S` переключают части. На телефоне — одна страница.
