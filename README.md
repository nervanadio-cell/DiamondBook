# DiamondBook

Библиотека, редактор и читалка книг для GitHub Pages.

## Обновлено

- Надписи на обложках одинаково масштабируются в предпросмотре и на полке. Название и автор автоматически разводятся, если накладываются друг на друга.
- 15 вариантов шрифта для обложки; 12 вариантов шрифта текста книги. Шрифт текста сохраняется внутри книги.
- В редактор добавлена вставка иллюстраций: обрезка, перемещение рамки, контраст, яркость, фильтры «Нуар», чёрно-белый и сепия, подпись и расположение. Можно отредактировать или удалить уже вставленную картинку.
- У книги на полке компактное меню «⋯»: редактор фото, оформление названия/автора и удаление.
- Иллюстрации видны в режиме чтения, включая перелистывание страниц.
- Сочетания клавиш: Shift+1–5 — оформление текста, Alt+1–5 — абзацы, Alt+0 — чтение, Ctrl+Alt+M — вставить фото.
