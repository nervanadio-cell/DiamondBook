# DiamondBook

Дубовая библиотека и редактор книг, подключённые к Cloudflare Pages и D1.

## Личная библиотека

Создание книг, главы, иллюстрации, обложки и редактирование хранятся **локально в браузере**, пока пользователь сам не публикует книгу. Для переноса между доменами используй экспорт и импорт JSON.

## Общественная библиотека

Под разделом «Мои книги» расположен каталог опубликованных книг:
- Поиск по названию, автору и никнейму.
- Фильтрация по жанру и сортировка.
- Профили с баннером, аватаром, описанием и ролью: писатель, читатель, редактор, иллюстратор или помощник автора.
- Регистрация, вход и сохранение профилей в Cloudflare D1.
- Публикация локальной книги только после явного согласия.
- Публичное чтение в режиме разворота, а также удаление своих публикаций.

**Ограничения первой версии:** почта не подтверждается, восстановление пароля ещё не реализовано. Не используй повторяющиеся пароли. Для публикаций действует лимит ~300 КБ текста и иллюстраций на книгу и до 40 публикаций на автора; картинки перед публикацией сжимаются.

## Развёртывание

- Хостинг: Cloudflare Pages, GitHub `nervanadio-cell/DiamondBook`, ветка `main`, корневая директория `/`, **без команды сборки**.
- Страницы HTML лежат в корне, серверные маршруты — `functions/api/[[path]].js`.
- D1: база `diamondbook-community`, binding `DB` (production и preview).
- SQL для восстановления схемы: `migrations/0001_community.sql`.
- После успешного запуска проверь `/api/health` — должен вернуть JSON с `ok: true`.
- Адрес проекта: https://diamondbook-nervanadio.pages.dev

**Статус на 2 ноября 2026:** Cloudflare Pages подтвердил успешный production-деплой ветки `main`. Для актуального статуса смотри список Deployments в Cloudflare. Новый визуальный слой и мобильные выдвижные панели описаны в [DESIGN_REFERENCE.md](DESIGN_REFERENCE.md).

Код интерфейса публичен на GitHub до ручной смены видимости. Приватный репозиторий не скрывает JS, передаваемый браузеру.
