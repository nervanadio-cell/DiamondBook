# DiamondBook

Локальная библиотека, редактор и читалка книг.

## Обновления

- Дубовые полки переработаны: текстура больше не растягивается, обложки увеличены, книги стоят непосредственно на досках. Информация и действия находятся под полкой.
- На ПК размещается до четырёх книг на полке, на планшете — до трёх, на телефоне — до двух.
- При создании тома и части больше не добавляются скрытые вложенные элементы. Главы и части можно добавить явно через `+` или контекстное меню.
- Контекстное меню тома позволяет отдельно создать часть или главу.
- Когда глав нет, редактор предлагает сначала создать главу, а не вставляет её без разрешения.
- Редактор иллюстраций по умолчанию показывает всю картинку, поддерживает обрезку и восстановление области, нуар/ЧБ/сепию, подписи и размер изображения.
- Иллюстрации вставляются самостоятельными блоками после абзаца с курсором и доступны для повторного редактирования.
- Горячая клавиша иллюстрации: `Ctrl+Alt+M`.
