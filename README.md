# DiamondBook

Локальный веб-редактор и читатель книг для GitHub Pages.

## Возможности

- Структура книги: тома, части и главы; переименование и добавление вложенных разделов.
- Редактор текста с форматированием и автосохранением в браузере.
- Редактор обложки: загрузка JPG/PNG/WebP/BMP, кадрирование, предпросмотр, сохранение в книге и скачивание JPG.
- Дубовый фон из пластин коры и полки из досок; обложки отображаются на книжной полке.
- Контекстное меню томов, частей и глав: переименование, добавление и подтверждаемое удаление; мультивыбор.
- Читалка-разворот на две страницы с анимацией и клавишами ←/→ для страниц, ↑/↓ для частей.
- Импорт и экспорт 36 форматов, включая EPUB, PDF, DOCX, ODT, FB2, TXT, HTML, Markdown и JSON.

## Запуск

Опубликуй репозиторий через GitHub Pages. Книги хранятся локально в браузере; для переноса используй экспорт JSON. Библиотеки для некоторых форматов загружаются с CDN и требуют интернет.
