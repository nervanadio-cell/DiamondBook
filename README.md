# DiamondBook

## Обновлено

- Фон сайта оформлен вертикальными пластинами дубовой коры; полки — отдельными досками дуба.
- На полке видны созданные и импортированные книги; обложку можно добавить или кадрировать прямо с полки.
- Правый клик по тому, части или главе открывает меню: переименовать, добавить вложенное, удалить с подтверждением или включить мультивыбор.
- Читалка показывает разворот из двух страниц с анимацией; `A/D` — перелистывание, `W/S` — переход между частями. На узком экране показывается одна страница.
- Редактор текста оформлен как бумажный лист, ограниченный окном; есть анимация переключения глав и закрытия книги.
