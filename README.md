# DiamondBook

## Обновлено

- Фон сайта оформлен дубовой корой; полки — дубовыми досками.
- Полка показывает книги с обложками; кнопку «Обложка» можно открыть прямо на полке.
- Контекстное меню содержания по правому клику: переименование, удаление с подтверждением, добавление вложенного раздела и мультивыбор.
- Редактор показывает текст на книжной странице; при смене главы есть анимация.
- Читалка показывает разворот из двух страниц; `A/D` — назад/вперёд, `W/S` — предыдущая/следующая часть. На узком экране используется одна страница.
